DESIGN PHILOSOPHY:
-----------------
• Card-based interface inspired by the reference image
• Purple gradient theme with pixelated heart elements
• Clean, modern medical device aesthetic
• Mobile-responsive design with smooth animations
• Distinct visual identity separate from original version

KEY FEATURES IMPLEMENTED:
------------------------

🎯 ACCURATE BPM CALCULATION:
• Real-time BPM calculation based on actual click timing
• No random values - purely based on user input intervals
• Dual calculation methods:
  - Interval-based for first 10 seconds (immediate feedback)
  - Average-based after 10 seconds (higher accuracy)
• 15-second measurement window for clinical accuracy
• BPM range clamped to realistic values (30-200 BPM)
• Smooth real-time updates as user continues clicking

🎤 ENHANCED MICROPHONE SYSTEM:
• Dedicated ON/OFF toggle switch in Breath Analysis card
• Reduced sensitivity (threshold increased) to ignore background noise
• Only significant audio levels trigger breath detection
• Independent microphone control - doesn't affect other app functions
• Visual feedback with breath quality percentage meter
• Gradual decay when no significant input detected

🎨 CARD-BASED UI STRUCTURE:
• Welcome Card: Pixel heart with measurement instructions
• Heart Rate Monitor Card: ECG graph with real-time BPM display
• Breath Analysis Card: Microphone toggle and quality meter
• Scene navigation with pagination (1/8, 2/8, 3/8)
• Action buttons (HOME, QUIT, PROFILE)

MEASUREMENT WORKFLOW:
--------------------
1. Power ON the system
2. Navigate to Heart Rate monitor (next button)
3. Click the heart or ECG graph to start measurement
4. Continue clicking at your heart rate rhythm
5. Real-time BPM calculation displays immediately
6. 15-second automatic measurement window
7. Final accurate BPM calculated at completion

MICROPHONE WORKFLOW:
-------------------
1. Navigate to Breath Analysis card
2. Toggle the switch to ON position
3. Grant microphone permission when prompted
4. Speak or breathe near microphone
5. Watch breath quality percentage update
6. Toggle OFF to disable without affecting other features
